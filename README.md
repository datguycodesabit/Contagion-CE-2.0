# CONTAGION CE

A strategy game for TI-84 Plus CE family calculators inspired by Plague Inc.

Spread a disease across seven regions, evolve transmissions and symptoms, manage
transportation, and defeat the cure before the outbreak ends.

## Download

[Download CONTAGION CE 2.0](bin/CONTAGION-CE-2.0.zip)

The package includes:

- `CNTAGION.8xp`
- `libload.8xv`
- `graphx.8xv`
- `keypadc.8xv`
- `fileioc.8xv`
- Installation instructions and credits

## Compatibility

- TI-84 Plus CE
- TI-84 Plus CE-T
- TI-83 Premium CE
- Native eZ80 calculator programs

On operating systems that restrict native programs, launch the game through
arTIfiCE or another native-program shell.

## Gameplay

Choose Bacteria, Virus, or Fungus, name your disease, and infect the world.

- Spread through seven regions
- Buy transmissions, symptoms, and abilities with DNA
- Use air and sea transportation
- Manage discovery, research, healthcare, and travel restrictions
- Virus can mutate symptoms
- Fungus can use three spore bursts
- Save and continue your game

Victory requires every land cell to die. You lose if active infection disappears
while healthy land remains or if the cure reaches completion.

## Controls

| Screen | Controls |
|---|---|
| Main menu | `Y=` New Game, `Zoom` Start/Continue, `Graph` or `Clear` Save and Quit |
| World map | Arrow keys select regions, `Enter` opens details, `Mode` changes travel view, `Graph` opens evolution |
| Evolution | `Y=` / `Window` change category, arrows move between nodes, `Enter` opens details |
| Trait details | `Enter` purchases, `Del` devolves eligible symptom leaves |
| Fungus abilities | `Zoom` opens the spore menu |
| Menus | `Graph` or `Clear` goes back |

Release each key before pressing another key.

## Installation

1. Transfer `CNTAGION.8xp` and the four `.8xv` libraries with TI Connect CE.
2. Launch `CNTAGION` through arTIfiCE or another native-program shell.
3. Start a new game with `Y=`.
